DblClick Launcher v1.0
Powered by Marius Filon


An ultra-lightweight and intuitive utility built with AutoHotkey v2, designed to transform your desktop into a high-speed launchpad. Stop hunting for icons; now you can access your favorite applications with a simple double-click on any empty space on your screen.

✨ Key Features
Instant Activation: The menu appears only when you double-click the Desktop background (Wallpaper).

Smart Scan: Includes an intelligent system to scan installed Windows programs for quick addition.

Total Customization: Manually add any file, folder, or executable to your list.

Easy Management: Reorganize your apps (Up/Down) or remove them using a clean graphical interface.

Native Integration: Option to launch automatically with Windows (Startup).

Modern Look: Automatically extracts application icons for a professional and polished appearance.

🛠️ How It Works
Run the App: Once started, it runs discreetly in the background.

Double-Click: Simply double-click anywhere on your desktop wallpaper.

Launch: Your custom menu instantly appears at your mouse cursor's location.

📥 Installation & Usage
For Users (Executable)
Download the latest version from the Releases section.

Run DblClick Launcher.exe.

Note: The application requests Administrator privileges to ensure it can launch other programs without security restrictions.

For Developers (Source Code)
If you prefer to run the script directly:

Install AutoHotkey v2.

Download the .ahk file.

Run the script by double-clicking it.

⚙️ Configuration
All your settings (application list and startup preferences) are automatically saved in a local .ini file located in the same folder as the program. This makes the application fully portable.

Un utilitar ultra-ușor și intuitiv creat în AutoHotkey v2, conceput pentru a-ți transforma desktop-ul într-un punct de lansare rapidă. Nu mai căuta prin zeci de iconițe; acum poți accesa aplicațiile preferate cu un simplu dublu-click pe spațiul liber de pe ecran.

✨ Funcții Principale
Activare Instantanee: Meniul apare doar când dai dublu-click pe fundalul Desktop-ului (Desktop Wallpaper).

Scanare Automată: Include un sistem inteligent de scanare a programelor instalate în Windows pentru adăugare rapidă.

Personalizare Totală: Adaugă manual orice fișier, folder sau executabil.

Gestiune Ușoară: Reorganizează ordinea aplicațiilor în meniu (Up/Down) sau șterge-le dintr-o interfață grafică simplă.

Integrare Nativă: Suport pentru pornire automată odată cu Windows-ul (Startup).

Vizual Modern: Extrage automat iconițele aplicațiilor pentru un aspect curat și profesional.

🛠️ Cum funcționează?
Deschide aplicația: Odată pornită, aceasta rulează discret în fundal.

Dublu-Click: Execută un dublu-click oriunde pe fundalul ecranului tău (Desktop).

Lansează: Meniul tău personalizat apare instantaneu la locația mouse-ului.
